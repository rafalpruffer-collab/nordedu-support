# NordEdu Support (Nordweco)

NordEdu Support to program do zarządzania pracownią komputerową, zbudowany na bazie
wolnego oprogramowania **Veyon** (https://veyon.io) w wersji 4.11.4.
Zmiany Nordweco: nazwa i grafiki (ikona, logo, ekran blokady „Patrz na tablicę”),
poprawione i uzupełnione tłumaczenie polskie, polski jako język domyślny.

Program jest udostępniany na licencji **GNU GPL v2** (plik `COPYING`), tak jak Veyon.
Pełny kod źródłowy = oryginalny Veyon v4.11.4 + plik `nordedu-support.patch` z tego repozytorium.
Paczka ze zrodłami (`NordEdu-Support-4.11.4-zrodla.tar.gz`) powstaje przy każdym budowaniu.

Budowanie: zakładka **Actions** → **Zbuduj NordEdu Support** → **Run workflow**.
Gotowy instalator pojawi się na dole strony uruchomienia, w sekcji **Artifacts**.
